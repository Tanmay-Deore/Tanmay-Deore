# External services used

Everything visual is a file in this repo (SVG), so the profile still looks complete if a service is down. Only these outside services are used:

| Service | Used for | If it fails |
|---|---|---|
| `github-stats-extended.vercel.app` | The GitHub stats card in "GITHUB ACTIVITY" | Delete that single `<img>` block in README.md. Nothing else depends on it. |
| `raw.githubusercontent.com` (your own repo, `output` branch) | Activity graph and contribution snake, generated by your GitHub Action every 12 hours | Run the workflow once from the Actions tab. |
| `panic-x.vercel.app` | The "PanicX · Live demo" link | Remove the link if the site is offline. |
| LinkedIn, GitHub, `mailto:` | Contact links | n/a |

Removed from the old design on purpose: shields.io badges, skillicons.dev icons, komarev profile-view counter, streak-stats card. They were extra dependencies or duplicate information.

## Technology logos

The logos in `assets/icons/` and on the project cards are drawn from the Simple Icons set (CC0 licence) and copied into the SVG files, so they load from your repo and not from a website. The logos themselves are trademarks of their owners.
